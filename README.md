# Django Helpdesk System

Sistema web de mesa de ayuda desarrollado con Django.

Proyecto orientado a la gestión de solicitudes de soporte técnico, seguimiento de incidencias y administración de tareas de equipos IT.

## Objetivo

Crear una solución backend que permita administrar el ciclo completo de atención de tickets, aplicando buenas prácticas de desarrollo, documentación y despliegue.

## Tecnologías previstas

- Python
- Django
- Django REST Framework
- PostgreSQL
- Docker
- Bootstrap

## Funcionalidades planificadas

### Usuarios y permisos

- Administrador
- Técnico
- Usuario

### Tickets

- Creación de solicitudes
- Estados del ticket
- Prioridades
- Categorías
- Asignación de responsables
- Historial de seguimiento

### Dashboard

- Tickets abiertos
- Métricas de atención
- Reportes
